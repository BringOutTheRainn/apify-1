# Apify Actors

Each folder is one Actor. Point Apify at a folder with the Git source URL
`https://github.com/BringOutTheRainn/apify-1#main:<folder>`.

| Folder | Actor |
|---|---|
| `podcast-leads` | Podcast Leads Finder: host emails, activity and guest score |
| `eu-legal-notice` | EU Company Legal Info Extractor: registration and VAT IDs from legal-notice pages |
